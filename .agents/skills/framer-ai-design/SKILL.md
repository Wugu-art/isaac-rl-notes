# Framer AI 设计交接

Framer AI 可生成视觉方案，但本项目的内容与发布源是 GitHub Pages/Jekyll。先把用户对导航、排版、交互和移动端的目标写成简短设计说明；若用户已提供 Framer 稿件，提取可实现的视觉规则，再改项目中的 HTML/CSS/JS。

Framer 草稿不会自动修改本仓库，也不会自动发布到当前网址。只有用户明确要求并具备相应连接时，才在 Framer 平台创建或编辑内容。保持学习笔记正文与网站技术元信息分离。
