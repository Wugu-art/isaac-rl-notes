# 学习日志

这里记录每天真正做过的实验、结论和下一步。建议文件名使用 `YYYY-MM-DD_主题.md`，并从[学习笔记模板](../学习模板/学习笔记模板.html)复制开始。

## 记录原则

1. 先写环境和版本，再写命令。
2. 区分“看到的现象”和“推测的原因”。
3. 失败实验也保留，因为它能避免重复踩坑。
4. 大型日志、模型和检查点不要提交 Git；只保留关键片段、曲线和结论。
5. 每篇结尾写一个可执行的下一步。
