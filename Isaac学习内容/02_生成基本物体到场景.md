# 02｜生成基本物体到场景（Spawn Prims）

> [!summary] 一句话
> **Prim 是 USD 场景中的一个节点；Cfg 定义物体是什么样，`cfg.func(路径, cfg, ...)` 把它放进场景。**

## 1. 先理解三个概念

- **Stage（舞台）**：整个 3D 场景。
- **Prim（基本体）**：场景中的节点，可以是物体、灯光、相机或分组。
- **Xform（变换节点）**：用于组织子节点、统一管理位置和旋转，本身不一定有可见几何体。

像文件夹一样理解场景树：

```text
/World
├── defaultGroundPlane
├── lightDistant
└── Objects                 ← Xform 分组
    ├── Cone1               ← 红色，只有外观
    ├── Cone2               ← 红色，只有外观
    ├── ConeRigid           ← 绿色，刚体 + 碰撞
    ├── CuboidDeformable    ← 蓝色，可变形体
    └── Table               ← 外部 USD 资产
```

## 2. 生成物体的通用套路（最重要）

```python
import isaaclab.sim as sim_utils

cfg = sim_utils.ConeCfg(radius=0.15, height=0.5)
cfg.func("/World/Objects/Cone1", cfg, translation=(-1.0, 1.0, 1.0))
```

- `ConeCfg(...)`：定义圆锥的半径、高度等配置。
- `"/World/Objects/Cone1"`：物体在 USD 场景树中的**路径**，不是磁盘文件路径。
- `translation=(x, y, z)`：放置位置，通常单位为米。
- `cfg.func(...)`：调用对应生成器，真正创建物体。
- `orientation=(w, x, y, z)`：四元数姿态，注意分量顺序。

> [!important] 记忆
> **Cfg = 定义；Spawner / cfg.func = 生成；Prim path = 场景中的地址。**

## 3. 本篇核心代码

### 3.1 地面

```python
cfg_ground = sim_utils.GroundPlaneCfg()
cfg_ground.func("/World/defaultGroundPlane", cfg_ground)
```

作用：为机器人提供地面。没有地面时，受重力作用的物体可能持续下落。

### 3.2 灯光

```python
cfg_light = sim_utils.DistantLightCfg(
    intensity=3000.0,
    color=(0.75, 0.75, 0.75),
)
cfg_light.func("/World/lightDistant", cfg_light, translation=(1, 0, 10))
```

- `DistantLightCfg`：方向性远光源。
- `intensity`：亮度；`color`：RGB 颜色。
- **灯光主要影响渲染，不直接提供机器人动力学。**

### 3.3 建立物体分组

```python
sim_utils.create_prim("/World/Objects", "Xform")
```

作用：创建父节点，让多个物体统一放在 `/World/Objects/` 下。

### 3.4 只用于显示的红色圆锥

```python
cfg_cone = sim_utils.ConeCfg(
    radius=0.15,
    height=0.5,
    visual_material=sim_utils.PreviewSurfaceCfg(
        diffuse_color=(1.0, 0.0, 0.0)
    ),
)
cfg_cone.func("/World/Objects/Cone1", cfg_cone, translation=(-1, 1, 1))
```

**只有外观配置，不代表自动拥有刚体和碰撞。** 该例中的红色圆锥不会像真实物体一样掉落。

### 3.5 会掉落和碰撞的绿色圆锥（重点）

```python
cfg_rigid = sim_utils.ConeCfg(
    radius=0.15,
    height=0.5,
    rigid_props=sim_utils.RigidBodyPropertiesCfg(),
    mass_props=sim_utils.MassPropertiesCfg(mass=1.0),
    collision_props=sim_utils.CollisionPropertiesCfg(),
    visual_material=sim_utils.PreviewSurfaceCfg(
        diffuse_color=(0.0, 1.0, 0.0)
    ),
)
cfg_rigid.func("/World/Objects/ConeRigid", cfg_rigid, translation=(-0.2, 0, 2))
```

| 配置 | 作用 |
|---|---|
| `rigid_props` | 启用刚体物理行为 |
| `mass_props` | 设置质量，此处 1 kg |
| `collision_props` | 添加碰撞属性 |
| `visual_material` | 设置外观颜色，不等于摩擦材质 |

**刚体 + 碰撞 + 质量** 是理解物理物体的重要组合。摩擦、恢复系数等需要根据物理材质或默认物理设置确定。

### 3.6 蓝色可变形长方体（了解即可）

```python
from isaaclab_physx.sim.spawners.materials import PhysxDeformableBodyMaterialCfg

cfg_soft = sim_utils.MeshCuboidCfg(
    size=(0.2, 0.5, 0.2),
    volume_deformable_props=[],
    visual_material=sim_utils.PreviewSurfaceCfg(diffuse_color=(0, 0, 1)),
    physics_material=PhysxDeformableBodyMaterialCfg(),
)
cfg_soft.func("/World/Objects/CuboidDeformable", cfg_soft, translation=(0.15, 0, 2))
```

- 用于橡胶、软体等可变形材料。
- 此例需要 GPU 仿真与四面体化依赖；与当前 Go2 刚体步态训练关系不大，先会识别即可。

### 3.7 导入已有 USD 模型

```python
from isaaclab.utils.assets import ISAAC_NUCLEUS_DIR

cfg_table = sim_utils.UsdFileCfg(
    usd_path=f"{ISAAC_NUCLEUS_DIR}/Props/Mounts/SeattleLabTable/table_instanceable.usd"
)
cfg_table.func("/World/Objects/Table", cfg_table, translation=(0, 0, 1.05))
```

- `UsdFileCfg`：引用已有 USD 资产到当前场景。
- `usd_path`：磁盘或资源服务中的**资产路径**，与 `/World/...` 场景路径不同。
- 表格是否具有碰撞，取决于资产中实际包含的物理配置。

## 4. 完整程序的执行顺序

```python
sim_cfg = sim_utils.SimulationCfg(dt=0.01, device=args_cli.device)
with launch_simulation(sim_cfg, args_cli):
    sim = sim_utils.SimulationContext(sim_cfg)
    sim.set_camera_view([2.0, 0.0, 2.5], [-0.5, 0.0, 0.5])
    design_scene()       # 先创建物体
    sim.reset()          # 初始化仿真
    while sim.is_running():
        sim.step()       # 推进物理时间
```

> [!warning] 顺序很重要
> **先创建场景，再 `sim.reset()`，最后循环 `sim.step()`。** 尤其在 GPU 仿真中，不建议在仿真运行中随意增删物理 Prim。

## 6. 和 Go2 项目有什么关系？

你以后会用同样思路：

- `GroundPlaneCfg`：生成平地测试环境。
- `UsdFileCfg`：加载机器人、障碍物或外部场景资产（机器人本身通常还需要 Articulation 配置）。
- `RigidBodyPropertiesCfg`、`MassPropertiesCfg`：为额外负载或可运动物体设置动力学。
- `CollisionPropertiesCfg`：让障碍物能够与 Go2 接触。

**注意：给 Go2 增加真实负重，不能只把一个有质量的物体放在背上；还要正确连接或固定负载，并检查质心和惯量。**

## 7. 常见易错点

1. **Prim 路径 ≠ USD 文件路径**：`/World/Objects/Cone1` 是场景节点，`table_instanceable.usd` 是资产文件。
2. **能看到 ≠ 能碰撞**：只配置颜色不等于配置刚体和碰撞。
3. **`sim.reset()` ≠ `sim.step()`**：前者初始化，后者推进仿真。
4. **视觉材质 ≠ 物理材质**：颜色和摩擦是两类不同属性。
5. **版本差异**：教程偏新版 API；你的 Isaac Lab 2.3.2 要按本地接口运行。
