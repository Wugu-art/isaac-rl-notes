# 01｜创建空场景

> [!summary] 一句话
> 学会从 Python 脚本启动仿真、初始化物理世界、循环推进仿真，以及退出时自动清理资源。

## 一、执行流程

命令行参数 → `SimulationCfg` 配置 → `launch_simulation` 启动 → `SimulationContext` 控制 → `reset()` 初始化 → `step()` 循环。

## 二、最关键的代码

以下是根据教程提炼的核心结构（省略部分注释）：

```python
import argparse
from isaaclab.app import add_launcher_args, launch_simulation
from isaaclab.sim import SimulationCfg, SimulationContext

parser = argparse.ArgumentParser()
add_launcher_args(parser)
args_cli = parser.parse_args()

sim_cfg = SimulationCfg(dt=0.01, device=args_cli.device)
with launch_simulation(sim_cfg, args_cli):
    sim = SimulationContext(sim_cfg)
    sim.set_camera_view([2.5, 2.5, 2.5], [0.0, 0.0, 0.0])
    sim.reset()
    while sim.is_running():
        sim.step()
```

## 三、逐项理解

| 代码 | 通俗解释 |
|---|---|
| `argparse` | 读取终端输入的参数 |
| `add_launcher_args(parser)` | 增加 Isaac Lab 的设备、可视化等启动参数 |
| `SimulationCfg(dt=0.01)` | 每次物理步推进 0.01 秒，即 100 Hz |
| `launch_simulation(...)` | 按配置启动所需的仿真运行时 |
| `with` | 离开代码块时自动清理运行时 |
| `SimulationContext(...)` | 控制仿真时间线、初始化和步进 |
| `set_camera_view(位置, 目标)` | 设置观察视角，不改变物理运动 |
| `reset()` | 初始化物理句柄并启动仿真；首次步进前必需 |
| `is_running()` | 判断是否继续运行 |
| `step()` | 推进一步物理仿真 |

## 四、怎么运行

在对应**新版** Isaac Lab 项目根目录中：

```bash
uv run python scripts/tutorials/00_sim/create_empty.py --viz kit
```

无图形界面：

```bash
uv run python scripts/tutorials/00_sim/create_empty.py
```

查看可用参数：

```bash
uv run python scripts/tutorials/00_sim/create_empty.py --help
```

> [!warning] 版本区别
> 本页对应新版 `add_launcher_args` / `launch_simulation` API。你当前的 Isaac Lab 2.3.2 主要使用 `AppLauncher`，不能直接复制新版脚本运行。也不要把 `--viz kit` 当成旧版的通用参数。

## 五、容易混淆的地方

- **`SimulationCfg` 与 `SimulationContext`**：前者是“参数清单”，后者是“实际控制仿真的对象”。
- **`reset()` 与 `play()`**：`reset()` 会初始化物理句柄；`play()` 只播放时间线。
- **`step()` 与 PPO 更新**：这里的 `step()` 是物理仿真步，不是神经网络更新一次。
- **空场景**：重点是学启动流程，尚未添加机器人、地面或传感器。

## 六、联系 Go2

以后训练 Go2，也要先启动仿真并建立环境，再加载机器人和物理配置。这里先掌握 **“配置 → 启动 → 初始化 → 步进”** 这条主线即可。

## 七、自测

1. `dt=0.01` 对应多少 Hz？（100 Hz）
2. 为什么第一次 `step()` 前要 `reset()`？（初始化物理处理）
3. `with` 退出后发生什么？（自动关闭/清理运行时）
